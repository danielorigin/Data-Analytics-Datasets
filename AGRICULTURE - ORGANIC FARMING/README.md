## About the Dataset

Synthetic dataset simulating real-world organic farming operations, covering crops, livestock, organic certifications, farm operations, sustainability, environmental impact, costs, revenues, and compliance. Suitable for Excel, SQL, Python/Pandas, Power BI, Tableau, R/RStudio, and data analytics projects.

## Context

Real agricultural and organic-farming data can be difficult to access due to commercial confidentiality, farm privacy, certification requirements, and operational data restrictions. This synthetic dataset provides a realistic alternative for analytics and portfolio development.

## Data Quality

The dataset contains realistic data-quality issues designed for analytics practice:

* 2–5% missing crop types and irrigation data
* 1.4% duplicate farm records
* Negative yield values
* Profit margins exceeding 100%
* Missing inspection results and notes
* Inconsistent certification labels such as `EU Organic`, `eu_organic`, and `EU_ORGANIC`
* Variations in compliance-status values

**Recommended workflow:**
Raw Data → Data Cleaning → Validation → Feature Engineering → Analysis → Visualization → Insights
