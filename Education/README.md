**Enrolment, Assessments, Financial & Student Outcomes — 2018–2025**

## About the Dataset

This synthetic education dataset was created to simulate **real-world student and academic records** and provide a practical dataset for learning, analysis, visualization, and portfolio development.

It contains student and course enrolment records covering **demographics, academic performance, attendance, courses, tuition, financial aid, scholarships, student support, internships, job placement, and alumni engagement**.

The dataset is suitable for:

**Excel · SQL · Python/Pandas · Power BI · Tableau · R/RStudio**

---

## Context

Real student and educational data can be difficult to access because of **privacy, confidentiality, and data protection requirements**.

This dataset provides a safe synthetic alternative for students, analysts, educators, and data professionals to practice working with realistic education data.

## Data Quality

The dataset intentionally contains realistic data-quality challenges, including:

* Missing values
* Inconsistent category values
* Mixed date formats
* Possible date contradictions
* Unusual records
* Fields requiring validation

The raw dataset is suitable for demonstrating:

> **Raw Data → Data Cleaning → Validation → Analysis → Visualization → Insights → Recommendations**

## Time Span

The dataset is intended to cover multiple academic years. The source description references **2018–2025**, while the raw-file notes also mention **2021–2025**.

Users should verify the actual minimum and maximum dates during data profiling before performing time-series analysis.

## Important Note

> **This is a fully synthetic dataset created for educational, analytical, practice, and portfolio purposes.**

It does not contain real student, academic, financial, or employment records.

The dataset should not be used to make real-world decisions regarding **admissions, grading, financial aid, academic progression, student risk, or employment**.
