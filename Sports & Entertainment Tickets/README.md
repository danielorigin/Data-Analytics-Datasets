**Ticket Sales — Sports Matches & Entertainment Events with Attendance**

## About the Dataset

This synthetic ticket sales dataset was created to simulate **real-world sports and entertainment event transactions** and provide a practical dataset for learning, analysis, visualization, and portfolio development.

It contains event- and ticket-level records covering **sports matches, concerts, festivals, ticket sales, attendance, customer satisfaction, merchandise purchases, and food & beverage spending**.

The dataset is designed to support practical analytics across **ticket sales, event performance, pricing, attendance, venue performance, customer satisfaction, and fan engagement**.

The dataset is suitable for:

**Excel · SQL · Python/Pandas · Power BI · Tableau · R/RStudio**

---

## Context

Real event and ticketing data can be difficult to access because of **privacy, commercial confidentiality, customer data protection, and business restrictions**.

This dataset was created as a safe synthetic alternative for students, analysts, data professionals, and portfolio developers who want to practice working with realistic sports and entertainment business data.

The dataset represents events held at **German venues**, including major cities such as **Berlin, Munich, Hamburg, and other locations**.

## Data Quality

The dataset intentionally contains some realistic data-quality challenges, making it useful for demonstrating a complete professional analytics workflow.

### Quality Issues

The dataset includes approximately:

* **2–5% missing values** in selected fields such as emails and satisfaction scores
* **1.4% duplicate tickets**
* Negative ticket prices
* Attendance records occurring before the associated purchase date
* Missing NPS scores
* Missing complaint types
* Other unusual records requiring investigation

### Completeness

* Event IDs are complete
* Ticket IDs are complete
* NPS scores contain some missing values
* Complaint types contain some missing values
* Selected customer information contains gaps

### Consistency

Some categorical fields contain inconsistent formatting, for example:

```text id="9kj6rw"
Standard
standard
STANDARD
```

Payment status fields may also contain variations requiring standardization during the data-cleaning process.

These issues provide opportunities to practice:

* Data profiling
* Data validation
* Missing-value treatment
* Duplicate detection
* Standardization
* Outlier detection
* Business-rule validation

It does **not** contain real customer, sports, event, venue, ticketing, or financial information.

The German venues, events, transactions, customers, attendance records, satisfaction scores, and financial values are artificially generated for analytics practice.

The dataset should not be interpreted as representing actual performance, attendance, pricing, customer behavior, or financial results of any real sports organization, entertainment company, venue, or event.
