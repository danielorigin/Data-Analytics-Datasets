# Data Analytics Datasets
![datasets logo](https://github.com/danielorigin/Data-Analytics-Datasets/blob/056d80e42392329b1301b671e84a50388cd26cb9/Datasets%20logo.png)
A collection of synthetic datasets created for data analytics,
business intelligence, data visualization, SQL, Python, R,
Power BI and Tableau projects.

- Agriculture

- Insurance
- Logistics & Supply Chain
- Real Estate
- Retail
- Renewable Energy
- Human Resources
- Sport & entertainment
- Finance
- E-commerce

## Dataset Characteristics

The datasets are synthetic and were created for analytical,
educational and portfolio development purposes.

They may contain realistic business patterns, missing values,
inconsistent values, outliers and other data-quality scenarios
designed to support practical data-cleaning and analysis workflows.

## Intended Use

These datasets can be used for:

- Exploratory Data Analysis
- SQL Analysis
- Python / Pandas
- R / RStudio
- Power BI
- Tableau
- Statistical Analysis
- Data Visualization
- Business Intelligence
- Portfolio Projects
