## About the Dataset

This synthetic insurance dataset was created to simulate **real-world insurance policies and claims** and provide a practical dataset for learning, analysis, visualization, and portfolio development.

It covers **auto, home, life, health, travel, and business insurance**, including policies, premiums, claims, settlements, risk, fraud indicators, underwriting, agents, commissions, customer satisfaction, and churn risk.

The dataset is suitable for:

**Excel · SQL · Python/Pandas · Power BI · Tableau · R/RStudio**

---

## Context

Real insurance data can be difficult to access because of **customer privacy, commercial confidentiality, and financial data protection requirements**.

This dataset provides a safe synthetic alternative for students, analysts, insurance professionals, and data professionals to practice working with realistic insurance data.

## Data Quality

The dataset intentionally contains realistic data-quality challenges, including:

* **2–5% missing values** in selected fields such as vehicle information and claim descriptions
* **1.3% duplicate policies**
* Claim amounts exceeding coverage limits
* Negative premium values
* Missing police report numbers
* Missing broker information
* Inconsistent policy statuses
* Claim status variations

## Important Note

> **This is a fully synthetic dataset created for educational, analytical, practice, and portfolio purposes.**

It does not contain real customer, policy, claims, financial, or insurance-company records.

Although the dataset simulates the **German insurance market**, all customers, policies, claims, premiums, risk scores, and financial values are artificially generated.

The dataset should not be used to make real-world decisions regarding **insurance pricing, underwriting, claims approval, fraud investigations, risk assessment, or customer eligibility**.
