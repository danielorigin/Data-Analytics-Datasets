**Online Retail Transactions — Customers, Products, Payments & Shipping — 2023–2025**

## About the Dataset

Synthetic dataset simulating real-world online retail operations, covering customer orders, products, pricing, payments, shipping, returns, customer behavior, and satisfaction. Suitable for Excel, SQL, Python/Pandas, Power BI, Tableau, R/RStudio, and data analytics projects.

## Context

Real e-commerce transaction data can be difficult to access due to customer privacy, commercial confidentiality, payment information, and proprietary business data. This synthetic dataset provides a realistic alternative for analytics and portfolio development.

## Data Quality

The dataset contains realistic data-quality issues designed for analytics practice:

* 2–5% missing satisfaction scores and return reasons
* 1.5% duplicate orders
* Inconsistent payment-status values such as `Completed`, `completed`, and `COMPLETED`
* Mixed date formats including ISO, `DD/MM/YYYY`, and `MM/DD/YYYY`
* Numerical errors in quantities and order totals
* Inconsistent payment methods, delivery statuses, and device types
* Optional customer-behavior fields with missing values

**Recommended workflow:**
Raw Data → Data Cleaning → Validation → Feature Engineering → Analysis → Visualization → Insights
