**Shipment Tracking & Delivery Data — Multi-Carrier, Multi-Modal Transport — 2022–2025**

## About the Dataset

This synthetic logistics dataset was created to simulate **real-world shipment tracking and supply chain operations** and provide a practical dataset for learning, analysis, visualization, and portfolio development.

It covers **multi-carrier and multi-modal transportation**, including shipments, routes, delivery performance, costs, vehicles, drivers, fuel consumption, CO₂ emissions, and delivery claims.

The dataset is suitable for:

**Excel · SQL · Python/Pandas · Power BI · Tableau · R/RStudio**

---

## Context

Real logistics and supply chain data can be difficult to access because of **commercial confidentiality, customer information, operational security, and proprietary transportation data**.

This dataset provides a safe synthetic alternative for students, analysts, logistics professionals, and data professionals to practice working with realistic supply chain data.

The dataset represents a **Germany-based logistics provider with international shipments across Europe**.

## Data Quality

The dataset intentionally contains realistic data-quality challenges, including:

* **2–5% missing values** in delivery times and proof-of-delivery information
* **1.4% duplicate shipments**
* Inconsistent delivery-status formats
* Distance and duration mismatches
* Missing customer satisfaction values
* Missing delay reasons
* Carrier-name variations

For example:

```text id="8s4m2k"
Delivered
delivered
DELIVERED
```

These issues provide opportunities to practice:

> **Raw Data → Data Cleaning → Validation → Analysis → Visualization → Insights → Recommendations**

## Important Note

> **This is a fully synthetic dataset created for educational, analytical, practice, and portfolio purposes.**

It does not contain real shipment, customer, carrier, vehicle, driver, financial, or operational records.

Although the dataset simulates a **Germany-based logistics provider**, all shipments, routes, carriers, delivery times, costs, vehicle information, fuel consumption, and emissions data are artificially generated.

The dataset should not be used to make real-world decisions regarding **transportation planning, carrier selection, route optimization, driver performance, delivery commitments, or operational safety**.
