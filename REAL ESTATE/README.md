**Residential & Commercial Property Listings with Pricing — 2022–2025**

## About the Dataset

This synthetic real estate dataset was created to simulate **real-world property listings and market activity** and provide a practical dataset for learning, analysis, visualization, and portfolio development.

It covers **residential and commercial properties**, including property characteristics, locations, pricing, agents, viewings, mortgages, investment metrics, neighborhood information, and property features.

The dataset is suitable for:

**Excel · SQL · Python/Pandas · Power BI · Tableau · R/RStudio**

---

## Context

Real estate market data can be difficult to access because of **commercial confidentiality, property-owner information, market restrictions, and data privacy requirements**.

This dataset provides a safe synthetic alternative for students, analysts, real estate professionals, and data professionals to practice working with realistic property-market data.

## Data Quality

The dataset intentionally contains realistic data-quality challenges, including:

* **2–5% missing values** in year renovated and mortgage rates
* **1.3% duplicate listings**
* Price-per-square-meter outliers exceeding **€100,000/m²**
* Negative property prices
* Missing school ratings
* Missing agent ratings
* Inconsistent property types
* Energy-rating variations

## Important Note

> **This is a fully synthetic dataset created for educational, analytical, practice, and portfolio purposes.**

It does not contain real property listings, customers, agents, transactions, mortgage records, or financial information.

Although the dataset simulates the **German real estate market**, all properties, prices, locations, agents, mortgage information, and market metrics are artificially generated.

The dataset should not be used to make real-world decisions regarding **property valuation, investment, lending, mortgage approval, property pricing, or real estate transactions**.
