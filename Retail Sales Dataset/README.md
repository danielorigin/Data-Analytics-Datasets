# Synthetic Sales Transactions Dataset

## About the Dataset

This synthetic sales dataset was created to simulate **real-world business transactions** and provide a practical dataset for learning, analysis, visualization, and portfolio development.

It contains **transaction-level sales data across multiple years**, covering business areas such as:

* Customers
* Products
* Categories
* Locations and regions
* Sales channels
* Pricing
* Discounts
* Payments
* Revenue
* Profit
* Transactions

The dataset is suitable for working with:

**Excel · SQL · Python/Pandas · Power BI · Tableau · R/RStudio**

---

## Context

Access to real-world business sales data can be limited because of privacy, confidentiality, and data protection requirements.

This dataset was created as a **safe synthetic alternative** for students, analysts, data professionals, and portfolio developers who want to practice working with realistic business transaction data.

The dataset also includes selected **missing, inconsistent, and unusual values** to provide opportunities for data cleaning, validation, and quality assessment.

---

## Inspiration

The dataset is designed to represent the types of challenges commonly encountered when working with business transaction data.

Rather than providing only perfectly clean data, it allows users to practice the complete analytics workflow:

> **Raw Data → Data Cleaning → Analysis → Visualization → Insights → Recommendations**

The dataset can be used to investigate a wide range of sales and business performance questions, including:

* How do sales change over time?
* Which products and categories perform best?

* How do discounts affect profitability?
* Which sales channels perform best?

* Which products, regions, or channels are underperforming?

## Key Performance Indicators

Common KPIs that can be calculated from the dataset include:

| KPI                           | Description                                        |
| ----------------------------- | -------------------------------------------------- |
| **Revenue**                   | Total sales revenue generated                      |
| **Profit**                    | Revenue remaining after applicable costs           |
| **Profit Margin**             | Profit expressed as a percentage of revenue        |
| **Quantity Sold**             | Total units sold                                   |
| **Transactions**              | Number of sales transactions                       |
| **Average Order Value (AOV)** | Average revenue generated per transaction          |
| **Discount Rate**             | Discount applied to transactions                   |
| **Return Rate**               | Proportion of transactions associated with returns |
